# AI Model Hub

Reference and download AI models from the [Hugging Face Hub] for Unity Sentis packages. Not affiliated with Hugging Face.

Package developers declare the models their package needs in a manifest. Package users get those models into their project with one click. See [VISION.md](VISION.md).

## Installation

Add the OpenUPM scoped registry for `tools.doji`, then add `tools.doji.model-hub`. See [Getting Started](docs/manual/getting-started.md#installation).
