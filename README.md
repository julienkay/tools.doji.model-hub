# HF Hub

Reference and download AI models from [HuggingFace] for Unity Sentis packages.

Package developers declare the models their package needs in a manifest. Package users get those models into their project with one click. See [VISION.md](VISION.md).

## Installation

Add the OpenUPM scoped registry for `tools.doji`, then add `tools.doji.hf-hub`. See [Getting Started](docs/manual/getting-started.md#installation).
